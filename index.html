Git & GitHub, from zero to submitting your work

A quick-reference guide put together for office hours and TA support. Read it top to bottom if you're new, or jump straight to the section you're stuck on.

Before you ask a TA

Most git problems fall into a handful of categories: merge conflicts, detached HEAD, accidentally committing to the wrong branch, or a rejected push. Check the Troubleshooting section first — you might fix it yourself in under a minute.

Guide sections

1. Git Basics

Install & configure git, understand the three areas, and learn the core commands: init, clone, add, commit, status, log, diff, and .gitignore.

2. Branching & Merging

Create and switch branches, merge changes, resolve conflicts, and understand when (and when not) to rebase.

3. GitHub Workflow

Forking vs. cloning, pull requests, code review, issues, a light intro to GitHub Actions, and a troubleshooting cheat sheet.

Quick command reference

CommandWhat it does
git statusShow what's changed and what's staged
git add <file>Stage a file for the next commit
git commit -m "message"Save staged changes as a new commit
git log --onelineShow commit history, one line per commit
git diffShow unstaged changes line by line
git branchList branches
git switch -c <name>Create and switch to a new branch
git merge <branch>Merge another branch into your current one
git pullFetch and merge changes from the remote
git pushUpload your commits to the remote
git clone <url>Copy a remote repository to your machine
git restore <file>Discard unstaged changes to a file

See the Git Basics page for the full explanation of each of these.
